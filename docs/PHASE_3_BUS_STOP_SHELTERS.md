# Phase 3: Roadside Bus Shelters

Added a restrained set of roadside bus shelters along selected avenues.

- Shelters use instanced meshes for posts, roof, translucent rear panel, and bench.
- Placement is deterministic and spaced across selected rows and blocks.
- The feature is visual only: it does not change collision, traffic, pedestrian navigation, delivery logic, or bike physics.
- Instancing keeps the added geometry to four draw calls.
